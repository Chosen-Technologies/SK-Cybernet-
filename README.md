# Cybernet App

The standalone Next.js user application for SK Cybernet.

## Development

```bash
npm install
npm run dev
```

The development server listens on port 3001. Configure public service URLs in `.env.local`; see `.env.example`.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The API, admin console, and marketing website are maintained as separate projects outside this repository.
